# 鍵位綁定參考

本頁列出了 Gitti 中所有可用的鍵位綁定，按上下文和場景進行組織。

## 圖例

- **`*`** = 全局鍵位綁定（在沒有彈出視窗時，適用於所有上下文）
- **`* [!!]`** = 全局鍵位綁定，**即使在彈出視窗打開時也有效**

| 鍵         | 標記     | 操作                 | 備註                                      |
| :--------- | :------- | :------------------- | :---------------------------------------- |

| `ctrl+s`   | `* [!!]` | 暫存所有檔案         | 暫存所有修改的檔案                        |
| `ctrl+u`   | `* [!!]` | 取消暫存所有檔案     | 取消暫存所有已暫存的檔案                  |
| `ctrl+g`   | `* [!!]` | 打開作者的 GitHub    | 在瀏覽器中打開作者的 GitHub               |
| `ctrl+l`   | `* [!!]` | 打開作者的 LinkedIn  | 在瀏覽器中打開作者的 LinkedIn             |

## 清單篩選

按 `F` 篩選當前聚焦的清單面板。每個清單保留各自的篩選內容。

| 鍵          | 操作             | 備註                                                                   |
| :---------- | :--------------- | :--------------------------------------------------------------------- |
| `F`         | 開始篩選         | 本地分支 / 標籤 / 遠端 / Worktree、修改的檔案、提交日誌 / RefLog、Stash |
| 任意字元    | 追加到篩選內容   | 每次按鍵都會重新篩選清單                                               |
| `backspace` | 刪除最後一個字元 | 每次按鍵都會重新篩選清單                                               |
| `enter`     | 套用並退出       | 保留篩選內容，其他按鍵恢復正常操作                                     |
| `esc`       | 清除並退出       | 清除篩選內容並恢復完整清單                                             |

- 篩選為對清單條目文字的**不區分大小寫的子字串**比對。
- 當前篩選內容顯示在面板的條目計數旁，例如 `3/10  /feat`。
- 輸入篩選內容時，其他鍵位綁定不會生效。請先按 `enter` 或 `esc`。
- 按 `enter` 後篩選內容仍然生效。若要清除，請再次按 `F`，然後按 `esc`。
- 彈出視窗打開時或處於行編輯模式時，`F` 無效。

## 滑鼠支援

| 操作             | 結果                                       |
| :--------------- | :----------------------------------------- |
| 左鍵點擊左側面板 | 聚焦該面板並選中點擊的清單項               |
| 左鍵點擊詳細面板 | 聚焦詳細面板；按 `esc` 返回清單面板        |
| 左鍵點擊日誌面板 | 聚焦日誌面板                               |
| 滾輪上 / 下      | 捲動聚焦的詳細面板，或已打開彈出視窗的內容 |
| 滾輪左 / 右      | 橫向捲動相同內容                           |

- 彈出視窗打開時、處於行編輯模式時，以及輸入篩選內容時，點擊會被忽略。
- 彈出視窗打開時滾輪仍然有效。

## 總結

- **`* [!!]`** 鍵位綁定在任何地方都有效，包括在彈出視窗內
- **`*`** 鍵位綁定全局有效，但在彈出視窗打開時無效
- **特定上下文的鍵位綁定**僅在其各自的面板中有效
- **彈出視窗鍵位綁定**取決於彈出視窗類型（文字輸入 vs 選擇 vs 輸出）
- **`esc`**是關閉彈出視窗或退出詳細檢視的通用方法
- **`F`** 篩選當前聚焦的清單面板，每個清單保留各自的篩選內容
- **滑鼠**點擊可聚焦面板並選中清單項；滾輪可捲動詳細面板和彈出視窗
